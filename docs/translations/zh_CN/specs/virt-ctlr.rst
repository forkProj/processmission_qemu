虚拟系统控制器
========================================

``virt-ctrl`` 为没有硬件参考实现的纯虚拟机定义了简单接口，
使客户机内核可以向主机虚拟机管理器发送命令。

规范可继续演进，当前定义如下。

此设备通过 MMIO 映射，占用 256 字节。

定义了两个 32 位寄存器：

功能寄存器（只读，地址 0x00）
   设备通过此寄存器报告控制器支持的功能。
   当前仅支持电源控制（0x01）。

命令寄存器（只写，地址 0x04）
   内核通过此寄存器向虚拟机管理器发送命令。
   已实现的电源控制命令为复位（1）、停止（2）、panic（3）。
   始终存在基本的空操作命令（0），可用来测试寄存器访问，不产生任何作用。
