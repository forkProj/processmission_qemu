========================================
QEMU PCI 串口设备
========================================

QEMU 实现了若干 PCI 串口设备，它们是一个或多个 16550 UART 的简单 PCI 包装。

包含一种单端口和两种多端口变体。Linux 客户机无需额外配置即可使用所有卡。
Windows 客户机可通过 ``docs/qemupciserial.inf`` 设置。


单端口卡
------------------------

名称：
  ``pci-serial``
PCI ID：
  1b36:0002
PCI 区域 0：
   长 8 字节的 I/O BAR，映射一个 16550 UART。
中断：
   连接到引脚 A。


多端口卡
------------------------

名称：
  ``pci-serial-2x``、``pci-serial-4x``
PCI ID：
  1b36:0003（ ``-2x`` ）和 1b36:0004（ ``-4x`` ）
PCI 区域 0：
   I/O BAR，依次映射两个或四个 16550 UART。
   第一个位于偏移 0，第二个位于偏移 8，依此类推。
中断：
   连接到引脚 A。
