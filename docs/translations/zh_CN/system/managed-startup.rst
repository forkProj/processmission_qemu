受管理的启动选项
========================

系统模拟中，可以用 ``-S`` 创建暂停状态的虚拟机。此时机器已按命令行完成
初始化，准备好执行客户机代码，但 VCPU 线程尚未执行。具体状态取决于启动方式：

- 初始状态，即复位或上电后的状态
- 直接加载内核时，初始状态可能被调整为执行 QEMU 载入客户机 RAM 的代码，
  也可能涉及传入迁移
- 接收迁移时，迁移完成后以迁入的机器状态更新初始状态

用户通常在此暂停点查询状态，或通过热插拔等方式继续配置，再允许客户机运行。

但 ``-S`` 暂停点不能修改影响初始创建的选项，例如 ``-smp``、``-m``、``-numa``，
也不能冷插入设备。实验性 ``--preconfig`` 可在初始机器创建前暂停，进入
preconfig 状态，允许通过 QMP 查询和配置，再按最终配置启动。

此状态只允许不依赖已初始化机器的有限 QMP 命令，包括但不限于：

- ``qmp_capabilities``
- ``query-qmp-schema``
- ``query-commands``
- ``query-status``
- ``x-exit-preconfig``
