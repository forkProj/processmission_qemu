QEMU 监视器
------------

QEMU 监视器用于向模拟器发送复杂命令，可以：

-  移除或插入 CD-ROM、软盘等可移动介质镜像。

-  暂停或恢复虚拟机，并将状态保存到磁盘文件或从中恢复。

-  不使用外部调试器就能检查虚拟机状态。

整数表达式
~~~~~~~~~~~~~~~~~~~

监视器的每个整数参数都支持整数表达式。在寄存器名称前加 *$*，
即可读取对应 CPU 寄存器的值。
