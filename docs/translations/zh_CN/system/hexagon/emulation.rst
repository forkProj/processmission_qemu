.. _Hexagon Emulation:

Hexagon CPU 架构支持
================================

TCG 支持 v65、v66、v67、v68、v69、v71 和 v73，以及以下架构扩展：

- HVX（Hexagon 向量扩展）

HVX 详情见 `Qualcomm Hexagon V73 HVX 程序员参考手册
<https://docs.qualcomm.com/bundle/publicresource/80-N2040-53.pdf>`_。
