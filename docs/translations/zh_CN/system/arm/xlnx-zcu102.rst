Xilinx ZynqMP ZCU102（``xlnx-zcu102``）
=======================================

该模型模拟 Xilinx ZynqMP ZCU102，具有 4 个 Cortex-A53 和 2 个 Cortex-R5F。

机器专用选项
""""""""""""""""""""""""

支持以下选项：

secure
  on/off 启用或禁用实现 Arm 安全扩展（TrustZone）的客户机 CPU，默认为 off。

virtualization
  on/off 启用或禁用实现 Arm 虚拟化扩展的客户机 CPU，默认为 off。
