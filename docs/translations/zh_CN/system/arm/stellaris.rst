Stellaris 开发板（``lm3s6965evb``、``lm3s811evb``）
===================================================

Luminary Micro Stellaris LM3S811EVB 模拟包含：

-  Cortex-M3 CPU

-  64k 闪存和 8k SRAM

-  定时器、UART、ADC 和 |I2C| 接口

-  |I2C| 总线上的 OSRAM Pictiva 96x16 OLED，使用 SSD0303 控制器

Luminary Micro Stellaris LM3S6965EVB 模拟包含：

-  Cortex-M3 CPU

-  256k 闪存和 64k SRAM

-  定时器、UART、ADC、|I2C| 和 SSI 接口

-  通过 SSI 连接、使用 SSD0323 控制器的 OSRAM Pictiva 128x64 OLED
