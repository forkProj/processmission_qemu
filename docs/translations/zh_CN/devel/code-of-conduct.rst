行为准则
========

QEMU 社区由来自世界各地的专业人士和志愿者组成。
多样性是我们的优势之一，但也可能造成沟通问题和不愉快。
因此，我们要求大家遵守以下基本规则。

* 友善接纳。我们致力于让所有人参与项目时免受骚扰，
  不因经验水平、性别、性别认同和表达、性取向、残障、外貌、体型、
  种族、族裔、年龄、宗教或国籍而受到区别对待。

* 相互尊重。大家不可能始终意见一致。社交和技术分歧时常发生，QEMU 社区也不例外。
  出现分歧时，应尝试理解原因，以建设性方式解决不同观点。
  社区成员与其他贡献者、社区外人员及 QEMU 用户交流时都应保持尊重。

骚扰和其他排斥行为不可接受。
让人感到不安或受威胁的社区，既不友善，也不尊重他人。
不可接受的行为包括：

* 使用带有性意味的语言或图像。

* 人身攻击。

* 挑衅，或发表侮辱、贬损言论。

* 公开或私下骚扰。

* 未经明确允许，公开他人的私人信息，例如住址或电子邮箱。

这不是穷尽所有禁止行为的清单。
请理解其初衷：帮助大家更好地善待彼此。

本准则适用于 QEMU 项目管理的所有空间，包括 IRC、邮件列表、问题跟踪系统、
社区活动，以及项目团队创建、供社区交流的其他论坛。
当个人以项目或社区代表、成员身份活动时，在上述空间之外也适用。

维护者采用本准则，即承诺在项目管理的各个方面公平、一致地应用这些原则。
如果认为有人违反准则，请阅读 :ref:`conflict-resolution`，了解如何处理。
