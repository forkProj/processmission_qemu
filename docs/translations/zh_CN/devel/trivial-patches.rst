小型补丁
========

概述
--------

只修改几行代码的小型补丁，虽然审查量很少，有时仍会长期滞留在邮件列表中。
没有归属活跃维护子系统的补丁尤其如此，容易被遗漏。

小型补丁团队负责审查并为符合以下条件的补丁创建拉取请求：

- 不属于活跃维护的子系统。
- 单个补丁或较短序列，最多 2～4 个补丁。
- 仅修改少量代码。

**如果认为补丁符合条件，应抄送 qemu-trivial@nongnu.org。**

仓库
--------

由于维护工作由团队成员轮值，同一时间只有一个活跃仓库：

- git://github.com/vivier/qemu.git trivial-patches - `浏览 <https://github.com/vivier/qemu/tree/trivial-patches>`__

工作流程
--------

团队成员轮流收集小型补丁。当值成员负责：

1. 从开发邮件列表识别小型补丁。
2. 审查并合入 Git 树，回复说明补丁已排队。
3. 每周向开发邮件列表发送一次拉取请求。

成员可以按意愿决定值班时长，建议一周后交给下一位。
