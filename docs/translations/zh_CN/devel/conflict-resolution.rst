冲突解决政策
============

社区冲突有多种形式：从某人心情不好而在邮件列表使用尖刻、伤人的语言，
到性别歧视、种族歧视言论或暴力威胁等严重违反行为准则的情况，以及两者之间的各种问题。

对于绝大多数问题，我们希望当事人先自行解决，必要时寻求帮助，
只有失败后才进一步升级处理。这使当事人对结果有更多掌控。

如何解决冲突
------------

发生冲突时，首先考虑直接与其他当事方讨论所感知到的问题，
最好通过 IRC 等实时渠道。
也可请第三方居中调解，例如共同朋友，或了解背景但未参与冲突的人。

如果没有效果，或不愿采用这种方式，或问题需要立即升级，
请发送邮件到 qemu@sfconservancy.org，向 QEMU 领导委员会报告，
并提供不当行为的相关记录。非常紧急时也可通过 IRC 通知一位或多位委员。
最新成员名单见 `QEMU Wiki <https://wiki.qemu.org/Conservancy>`__。

委员会对报告保密，未经同意不会公开。
委员会会尽力及时审查事件，随后进一步收集信息，或决定下一步行动。

处理措施
--------

向委员会升级问题，可能导致影响一位或多位当事人的措施。
需要介入时，委员会可能采取：

1. 不采取行动。例如投诉未经证实、出于恶意，或不在委员会职责范围内。

2. 私下告诫一位或多位当事人，说明持续该行为的后果。

3. 私下告诫，并要求私下或公开道歉。

4. 公开告诫，并要求公开道歉。

5. 公开告诫并要求冷静期。冷静期可能要求暂停维护职责；
   不与相关人员互动，包括主动联系执行准则的人和社交媒体互动；
   或不得参加线下活动。冷静期依靠自愿遵守，但可升级为临时禁令以落实。

6. 暂时或永久禁止参加部分或全部现有及未来 QEMU 空间，
   包括邮件列表、IRC、Wiki 等，也可能包括线下活动。

遇到严重骚扰，委员会可能建议向当地相关执法机构报告。
但代表事件当事社区成员主动联系执法机构，不属于委员会职责。
