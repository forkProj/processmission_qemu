VNC LED 状态伪编码
================================================

简介
------------------------

本文描述 VNC 所用 RFB 协议的 LED 状态伪编码，参考协议：

http://tigervnc.svn.sourceforge.net/viewvc/tigervnc/rfbproto/rfbproto.rst?content-type=text/plain

通过 VNC 控制台访问客户机时，VNC 客户端所在计算机的锁定键 LED，
可能与客户机中的实际锁定键状态不一致。

为解决此问题，向 VNC 协议添加 LED 状态伪编码扩展，用于设置 LED。

伪编码
------------------------

客户端请求此伪编码，表示支持协议的 LED 状态扩展。

LED 状态的伪编码号定义如下：

======== ===============================================================
编号     名称
======== ===============================================================
-261     LED 状态伪编码
======== ===============================================================

LED 状态伪编码
----------------------------------------

LED 状态包含 3 位，从左到右分别表示 Caps、Num 和 Scroll Lock。
1 表示 LED 应亮起，0 表示应熄灭。

编码示例：

======== ===============================================================
编码     说明
======== ===============================================================
100      CapsLock 亮，NumLock 和 ScrollLock 灭
010      NumLock 亮，CapsLock 和 ScrollLock 灭
111      CapsLock、NumLock 和 ScrollLock 全亮
======== ===============================================================
